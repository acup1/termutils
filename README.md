# termutils examples

Run any fullscreen example directly from the `examples` branch:

```sh
nix run github:acup1/termutils/examples#snake
nix run github:acup1/termutils/examples#paint
nix run github:acup1/termutils/examples#life
```

The individual [`snake`](snake/README.md), [`paint`](paint/README.md), and
[`life`](life/README.md) README files document controls and local development
commands.
